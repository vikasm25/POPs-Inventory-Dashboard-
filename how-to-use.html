How to Use POPs Atlas

A guided explanation of the map, filtering, emissions comparisons and interpretation.

1. Choose an inventory

Use the Inventory dropdown above the map to select one available inventory. The map, charts, source categories and analyses follow this selection. Inventories are independent and are not added together.

2. Select exactly one pollutant

Select one pollutant from the Pollutant dropdown next to Inventory. Available pollutants depend on the selected inventory. The published EDGAR PCB dataset represents aggregated unintentional PCBs: it is not PCB-28 or any other individual congener.

3. Include or exclude sources

Use the emission-source checkboxes to filter by sector. All restores all available source categories, while None clears them. Categories depend on the chosen inventory/pollutant and should not be interpreted as identical between unrelated inventories without a documented crosswalk.

4. Explore countries or global totals

Click a country or a row in the table to inspect that country. Click Global to return to the sum across countries with reported values. Drag the map to pan after zooming, and use +, − and reset to change its scale.

5. Switch between Map and Table

Map displays the geographic emissions. Table replaces the map and its color legend rather than appearing below them. Table rows can also select a country.

6. Explore time

Use the year slider to switch years. Press Play to animate to the end of the available period; it stops automatically. The map legend uses a logarithmic scale held constant across years for a given pollutant/inventory/source selection, with the upper end capped at the 98th percentile of positive country-year totals.

7. Read the graphs correctly

Key Statistics, Emissions Over Time, source-category fractions, regional distribution and emissions insights summarize the currently chosen inventory. A percentage and an annual mass (tonnes/year) are shown for each nonzero source in the category graph.

8. Understand missing data

Dark gray means no observation, not zero. The near-white shade marks a reported zero. The global total is the sum of reported country values and is not necessarily a complete estimate if source coverage is partial. Geographic groupings are country-level assignments.

9. Download and cite responsibly

The Export button downloads observations for the current selection. When reporting results, identify the exact inventory, pollutant, year, units and source categories; cite the corresponding data source.
