DASHBOARD WORKFLOW

From selection to evidence

Use these steps in order when starting a new question.

01

Set the inventory and scenario

Choose EDGAR v8.1 POPs or Breivik PCBs. Breivik also asks for Baseline, Default or Worst case. These inventories remain separate and are never added together.

02

Choose one pollutant

Available pollutants change with the inventory. EDGAR's PCB (aggregate, unintentional) is an aggregate series, not PCB-28. Breivik lists individual congeners and Σ22 PCBs.

03

Set source categories

Use Emission Sources to include the categories you need. All restores every available category and None clears them. Breivik has no source-sector breakdown, so its source card is intentionally unavailable.

04

Read the map and color key

The main map uses a logarithmic emissions scale for the active year. Dark gray means no country observation and the light swatch means a reported zero. Hover a country for its value; use the map, table, zoom and reset controls as needed.

05

Move through time

Drag the Time explorer slider or press Play. The map, global statistics, source donut, regional chart and country rankings update for the selected year. Playback stops at the final year.

06

Inspect a country or the table

Click a map country or table row to update the selected-location card and trend. Click Global ↺ to return to reported worldwide totals. Offshore and unassigned records can remain in global totals without appearing as countries.

07

Use the focused analysis panel

Scroll to Explore the data and choose the question that matches your task. The controls change to show only the inputs needed for that analysis.

08

Export a reproducible slice

Export data downloads the active inventory, pollutant, year, country selection and source categories as CSV, including values in tonnes/year. Record those filters with any result you share.

FOCUSED ANALYSIS

Choose the question, then read the matching result

Each view keeps the interaction close to the result it explains. The focused analyses use their own selections, so the main map's source checkboxes do not change them. In Compare pollutants, EDGAR sources are summed only within the line where you selected them.

A

Compare pollutants

Add up to six pollutant series; on wide screens the controls arrange three series per row. Each series names the inventory and pollutant plus its context: choose exactly one Breivik scenario, or select one or more EDGAR source categories whose emissions are summed for that line. The plot keeps only shared years, and hovering by year shows every selected value with its full context.

B

Find the peak year

Choose one inventory, its scenario or EDGAR source total, a pollutant and a selected year. The line marks the highest annual total and the selected year. Hover anywhere on the plot to inspect the annual value at that year.

C

Spatial year comparison

Choose one inventory, its scenario or EDGAR source total, a Reference year and a Target year. The map shows percentage change only for countries observed in both years. Zero is the center of the diverging scale; missing either year is shown as No observation and is excluded from the percentage calculation.

INTERPRETATION CHECKS

Keep these distinctions in view

A

Missing is different from zero

POPs Atlas does not interpolate or fill missing country-year values. A reported zero is a real observation and uses a separate map shade.

B

Totals describe reported records

Global totals and shares summarize loaded observations. They do not prove complete global coverage, and independent inventories should not be combined.

C

Units and definitions matter

Values are tonnes/year. EDGAR PCDD/F toxic-equivalency values are excluded from this mass-based display. Check the inventory notes before comparing substances.
